# 备份与恢复手册

## 1. 什么需要备份

| 组件 | 角色 | 备份？ |
| --- | --- | --- |
| PostgreSQL | **唯一真相源**：知识库、来源、文档/chunk、Evidence、知识项与修订、发布、授权、检索日志、单元向量（`unit_embeddings`）、加密后的 Warehouse 凭证 | 是，定期 |
| Weaviate | ANN 加速层，内容全部可由 `unit_embeddings` 重建 | 否，恢复后重建 |
| Warehouse 对象存储 | 资产原文，由 Warehouse 自身负责 | 不在本服务范围 |
| `.env` / 密钥 | `JWT_SECRET`、`TOKEN_ENCRYPTION_SECRET` 等 | 是，单独的密钥管理。**丢失 `TOKEN_ENCRYPTION_SECRET` 将无法解密已存的 Warehouse 凭证** |

## 2. 备份

```bash
scripts/backup_db.sh                       # pg_dump 自定义格式 → backups/knowledge-<UTC>.dump
BACKUP_VIA_COMPOSE=1 scripts/backup_db.sh  # 在 compose 的 postgres 容器内执行
```

建议：每日全量 + 保留 14 天；上线前、迁移前、批量删除前手动各备一次；备份文件离机存放并校验可读（`pg_restore --list <dump> | head`）。

## 3. 恢复

1. 停止 API 与 worker（避免写入与租约争用）。
2. 恢复数据库（会覆盖现有对象）：
   ```bash
   RESTORE_CONFIRM=yes scripts/restore_db.sh backups/knowledge-<UTC>.dump
   # 或 RESTORE_CONFIRM=yes RESTORE_VIA_COMPOSE=1 scripts/restore_db.sh ...
   ```
3. 启动 API：lifespan 自动 `alembic upgrade head`（备份早于当前代码版本时补齐迁移）；或手动 `.venv/bin/alembic upgrade head && .venv/bin/alembic check`。
4. 重建向量加速层（仅 `VECTOR_STORE_MODE=weaviate`）：对每个知识库调用 `POST /kbs/{kb_id}/reindex-units`（幂等，按 `text_hash` 跳过未变更单元并镜像写入 Weaviate）。Weaviate 数据卷可直接清空后重建。
5. 启动 worker。

## 4. 验证清单

- `GET /health` 200；`/ops/stores/health` 数据库 `ok`。
- `alembic check` 无漂移。
- 抽样对比恢复前后计数：`/ops/overview` 的 `knowledge_bases / documents / chunks / retrieval_logs`。
- 控制台打开任一知识库概览、文档列表、知识项详情（证据链可回查）、当前发布。
- 检索台跑一次对比；日志 trace 中 `vector_signal` 应为 `active`（Weaviate 重建完成）或 `active_no_index`（尚未重建，仍可用但为关键词检索）。
- 用一个消费方 API Key 调 `POST /service/search` 成功。

## 5. 演练记录

每次演练记录：备份文件、恢复耗时、迁移是否需要补齐、重建向量耗时、验证清单结果与问题。首次演练应在接入真实 Warehouse 与模型网关的预生产环境完成，并作为 P0「运维基线」的验收证据。

## 6. 常见问题

- **恢复后登录态失效**：JWT 由 `JWT_SECRET` 签发，密钥未变则不受影响；若轮换了密钥，用户重新登录即可。
- **Warehouse 凭证解密失败**：`TOKEN_ENCRYPTION_SECRET` 与备份时不一致。恢复正确的密钥，或在控制台 Warehouse 页重新录入 / 一键初始化凭证。
- **任务卡在 running**：恢复时点有进行中的任务，其租约在 `WORKER_RUN_LEASE_TTL_SECONDS` 后过期并被 worker 接管；也可在任务页取消后重试。
- **Weaviate 维度不匹配**：备份与当前 `EMBEDDING_MODEL / EMBEDDING_DIMENSIONS` 不同，按《向量索引运维手册》重建 class 后再全量再索引。
