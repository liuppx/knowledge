# 上链到知行图

把一条已接受的知识项发布到[知行图](https://blockchain.yeying.pub)——社区公开、可验证的知识图。
链上记录谁写的、依据什么、来源(人工 / 哪个模型),其他成员在链上核验;任何人都能按 JSON-LD 词表取用
(见知行图仓库 `docs/design/ontology-v0.1.md`)。

## 需要什么

- **夜莺钱包**里有一个知行图账户(「账户管理 → 导入钱包」,网络选「知行图」),而且这个账户已经是知行图测试网成员;
- 管理员在 Knowledge 配好:`KDG_MODE=live`、`KDG_WRITE_TOKEN`(知行图组织者提供,只防刷写入)。默认 `disabled`,功能不开放。

## 怎么做

1. 打开知识项详情,在「知行图」一节选**领域**与**层级**;是模型写的就填**模型来源**,经过人工修改核对再勾选那一项。点「保存上链设置」。
2. 需要的话添加**引用**:依据(这条知识建立在哪条之上)、参见、取代。被引用的条目要先上链。
3. 点「上链到知行图」:钱包先请你确认连接,再弹出要签的内容(例如"创建新知识单元(基础层,领域 2)"),确认后签名。
4. 几秒后显示「已上链:知行图单元 #N vM」,点它可以打开链上的单元页。

之后修改这个知识项产生新修订,再点一次就会发布为**同一单元的新版本**。已上链的条目不能再改领域与层级。

## 边界

- **Knowledge 不接触私钥**:签名在钱包里完成。后端只组好意图交给钱包,收到签名后核对"签的正是这条意图、签名对你的公钥有效",
  再提交到链;核对不过就不提交。
- 正文放在知行图的正文仓库里(按内容哈希寻址,不可篡改);Knowledge 只记哈希与链上的单元号。
- **核验不在这里做**:链上的核验必须由其他成员完成。

## 常见问题

| 提示 | 原因 |
| --- | --- |
| 钱包里还没有知行图账户 | 先在钱包「账户管理 → 导入钱包」里导入 |
| 不是测试网成员 | 把钱包里知行图账户的公钥发给邀请你的成员 |
| 被引用的条目还没上链 | 先把它上链 |
| 上一次上链还在等待链上确认 | 稍等几秒点「刷新上链状态」 |
| 知行图上链未开启 | 管理员还没配置 `KDG_MODE=live` |
